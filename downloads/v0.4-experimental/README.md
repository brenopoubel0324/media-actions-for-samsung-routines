No app: **Widget appearance → Icon style → Outline / Rounded / Classic**.
Ajuste **Button spacing** até 64 dp ou marque **Spread buttons across the full widget width**, depois toque em **Apply to widgets**. Aumente a largura no LockStar para liberar gaps maiores.

O APK atualiza as versões anteriores com a mesma assinatura. Fundo transparente, cores branca/escura e tamanho dos ícones continuam disponíveis.

88 testes de host e lint passaram. Comportamento real no LockStar/tela bloqueada ainda requer validação no S25. A imagem é uma renderização nativa do Android, não uma captura do aparelho.
